# 图标分离方法测试说明

## 功能概述

`test_all_separation_methods.py` 脚本用于测试所有可用的图标分离方法，并为每种方法生成完整的预览图。

## 预览图格式

每个方法都会生成一个预览图，文件名格式：`{方法名}_preview.png`

预览图包含4个部分（2x2布局）：
1. **原图** - 原始图标
2. **前景** - 分离出的前景（背景透明）
3. **背景** - 分离出的背景（前景区域透明）
4. **合并效果** - 前景和背景合并后的效果

## 支持的分离方法

### 1. GrabCut
- **依赖**: `opencv-python`
- **安装**: `pip install opencv-python`
- **特点**: 基于图像分割算法，速度快，适合简单图标

### 2. U2Net (rembg)
- **依赖**: `rembg`, `onnxruntime`
- **安装**: `pip install rembg onnxruntime`
- **特点**: 基于深度学习的背景移除，效果最好

### 3. SAM2
- **依赖**: `opencv-python`
- **安装**: `pip install opencv-python`
- **特点**: 使用GrabCut作为fallback，适合复杂图标

## 方法对比

### 性能对比

| 方法 | 速度 | 质量 | 适用场景 |
|------|------|------|----------|
| GrabCut | 快 | 中等 | 简单图标，背景单一 |
| U2Net | 慢 | 最好 | 复杂图标，需要高质量 |
| SAM2 | 中等 | 中等 | 复杂图标，需要平衡 |

### 选择建议

- **简单图标**（纯色背景）: 使用 GrabCut
- **复杂图标**（渐变背景）: 使用 U2Net
- **批量处理**: 使用 GrabCut（速度快）
- **高质量要求**: 使用 U2Net

## 故障排除

### 1. 缺少依赖

**错误**: `ImportError: No module named 'cv2'`
**解决**: `pip install opencv-python`

**错误**: `ImportError: No module named 'rembg'`
**解决**: `pip install rembg onnxruntime`

### 2. 预览图生成失败

- 检查Pillow是否正确安装
- 确认前景和背景图片已成功生成
- 查看错误信息，可能是图片格式问题

### 3. 分离效果不佳

- 尝试不同的方法（U2Net通常效果最好）
- 检查原始图标质量
- 对于复杂图标，可能需要手动调整

## 注意事项

1. **首次运行U2Net**: 会自动下载模型文件（约100MB），需要网络连接
2. **内存使用**: U2Net需要较多内存，处理大图标时注意
3. **处理时间**: U2Net较慢，批量处理时建议使用GrabCut
4. **预览图尺寸**: 默认512x512，可在脚本中调整
