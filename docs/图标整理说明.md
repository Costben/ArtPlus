# 应用图标整理工具使用说明

## 功能说明

这个工具用于整理 `outputs/new_artplus` 目录下已提取的应用图标：
- 在每个应用包名目录下创建 `src` 子文件夹
- 将所有原始提取的图标文件（PNG、XML等）移动到 `src` 文件夹中
- 智能选择一个最适合的PNG图标，转换为240x240的标准尺寸，保存为 `recfg.png`

## 前置要求

1. **Python 3.6+** - 已安装Python
2. **Pillow 库** - 运行以下命令安装：
   ```bash
   pip install Pillow
   ```
3. **已运行图标提取工具** - 确保 `outputs/new_artplus` 目录已存在，并且其中包含了通过 `extract_app_icons.py` 提取的原始图标文件

## 使用方法

### 方式1: 使用启动脚本（推荐）

按系统运行 `launch/` 下的 `02-拉取APK并提取和整理图标`（第2步即为整理图标）：
- Windows：`launch\windows\02-拉取APK并提取和整理图标.bat`
- macOS：`bash launch/macos/02-拉取APK并提取和整理图标.sh`
- Linux：`bash launch/linux/02-拉取APK并提取和整理图标.sh`

### 方式2: 命令行运行

```bash
python cli/convert_and_organize_icons.py
```

## 工作流程

1. **遍历应用目录** - 扫描 `outputs/new_artplus` 目录下的所有应用包名文件夹
2. **选择最佳图标** - 按照以下优先级选择最佳的PNG图标：
   - `ic_launcher_foreground.png` (自适应图标前景) - 最高优先级
   - `ic_launcher_round.png` (圆形启动器图标)
   - `ic_launcher.png` (标准启动器图标)
   - 其他PNG文件（选择分辨率最高的）
3. **转换尺寸** - 将选定的图标调整为240x240像素（ART+图标标准尺寸）
4. **保存图标** - 保存为 `recfg.png` 到应用根目录
5. **移动原始文件** - 将所有原始提取的文件移动到 `src` 目录

## 图标转换规则

### 尺寸调整
- 如果图标是正方形，直接缩放到240x240
- 如果图标不是正方形，先居中裁剪为正方形，再缩放到240x240
- 保持透明通道（RGBA模式）

### 格式要求
- 输出格式：PNG
- 输出尺寸：240x240像素
- 颜色模式：RGBA（支持透明）

## 注意事项

### XML图标处理

如果一个应用只有XML格式的图标（例如 `ic_launcher.xml` 或 `mipmap-anydpi-v26_ic_launcher.xml`），本工具无法自动将其渲染为PNG。这是因为：

1. **Android Vector Drawable** - 需要Android SDK工具才能正确渲染
2. **Adaptive Icon XML** - 需要合并前景和背景层，需要专门的工具

对于这类应用，您可以：
- 使用Android SDK的 `aapt` 或 `drawable` 工具
- 使用在线工具转换XML为PNG
- 手动从APK中提取对应的PNG资源

### 重复运行

如果重复运行脚本：
- 会重新整理文件
- 会重新生成 `recfg.png`（覆盖旧文件）
- 原始文件会重新移动到 `src` 目录

### 文件冲突

如果 `src` 目录中已存在同名文件，脚本会自动添加序号避免覆盖：
- `ic_launcher.png` → `ic_launcher_1.png`

## 后续步骤

转换完成后，您可以：

1. **检查图标质量** - 查看生成的 `recfg.png` 是否符合要求
2. **手动优化** - 对于转换效果不理想的图标，可以手动编辑
3. **制作ART+图标** - 参考ART+图标规范，制作完整的图标套件：
   - `recbg.png` - 经典亮色背景
   - `recfg.png` - 经典亮色前景（已生成）
   - `rec_night.png` - 经典暗色
   - `monochrome.png` - 灵感样式
   - `day.png` - 彩昼
   - `nsd.png` - 夜影
   - `mat.png` - 材料
   - `peb.png` - 鹅卵石

## 故障排除

### 问题1: 未安装Pillow

**错误信息：**
```
警告: 未安装Pillow库
```

**解决方案：**
```bash
pip install Pillow
```

### 问题2: 图标转换失败

**可能原因：**
- 图片文件损坏
- 不支持的图片格式
- 权限问题

**解决方案：**
- 检查原始文件是否完整
- 确认文件权限
- 查看错误信息中的具体原因

### 问题3: 只有XML图标

**现象：**
```
[WARN] 只有XML图标，无法自动转换（需要Android SDK工具）
```

**解决方案：**
- 这是正常现象，XML图标需要专门的工具处理
- 可以尝试从APK的其他位置查找PNG资源
- 或使用Android SDK工具转换
