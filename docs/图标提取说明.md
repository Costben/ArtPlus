# 应用图标批量提取工具使用说明

## 功能说明

这个工具可以通过adb批量从手机上已安装的应用APK中提取原始图标资源，包括：
- PNG格式图标
- XML格式矢量图标
- SVG格式图标
- 分层图标（前景/背景）
- 不同尺寸的图标（hdpi、xhdpi、xxhdpi等）

## 前置要求

1. **Python 3.6+** - 已安装Python
2. **ADB工具** - 已安装并添加到系统PATH
3. **手机连接** - 手机已通过USB连接并开启USB调试
4. **应用列表** - 已有 `outputs/reports/missing_artplus_icons.json` 文件

## 使用方法

### 方式1: 使用启动脚本（推荐）

按系统运行 `launch/` 下的 `02-拉取APK并提取和整理图标`（第1步会拉取并提取图标）：
- Windows：`launch\windows\02-拉取APK并提取和整理图标.bat`
- macOS：`bash launch/macos/02-拉取APK并提取和整理图标.sh`
- Linux：`bash launch/linux/02-拉取APK并提取和整理图标.sh`

### 方式2: 命令行运行

```bash
python cli/extract_app_icons.py
```

## 工作流程

1. **检查adb连接** - 验证手机是否已连接
2. **读取应用列表** - 从 `outputs/reports/missing_artplus_icons.json` 读取缺失应用列表
3. **获取APK路径** - 通过 `adb shell pm path` 获取每个应用的APK路径
4. **拉取APK文件** - 使用 `adb pull` 将APK文件下载到临时目录
5. **提取图标资源** - 从APK中查找并提取所有图标文件
6. **保存到目录** - 将提取的图标保存到 `outputs/new_artplus/包名/` 目录下
7. **清理临时文件** - 删除临时APK文件

## 提取的图标类型

工具会尝试提取以下类型的图标：

### 标准图标
- `ic_launcher.png` / `ic_launcher.xml`
- `ic_launcher_round.png` / `ic_launcher_round.xml`
- `ic_launcher_monochrome.png` / `ic_launcher_monochrome.xml`

### 分层图标（Android 8.0+）
- `ic_launcher_foreground.png` / `ic_launcher_foreground.xml`
- `ic_launcher_background.png` / `ic_launcher_background.xml`
- `ic_launcher_adaptive_foreground.png`
- `ic_launcher_adaptive_background.png`

### 其他常见名称
- `app_icon.png`
- `icon.png`
- `logo.png`

### 不同尺寸
工具会提取所有尺寸的图标：
- `mipmap-mdpi` - 中等密度
- `mipmap-hdpi` - 高密度
- `mipmap-xhdpi` - 超高密度
- `mipmap-xxhdpi` - 超超高密度
- `mipmap-xxxhdpi` - 超超超高密度

## 输出文件命名

提取的文件会按以下规则命名：
- 单文件：`mipmap-hdpi_ic_launcher.png`
- 如果文件名重复，会添加序号：`mipmap-hdpi_ic_launcher_1.png`

## 注意事项

1. **aapt工具（可选）**
   - 如果系统中有 `aapt` 工具，工具会使用它来更准确地识别图标资源
   - 如果没有aapt，工具会使用文件名模式匹配，也能提取大部分图标

2. **跳过已有图标**
   - 默认会跳过已有图标文件的目录
   - 可以在运行时选择是否跳过

3. **网络速度**
   - 拉取APK文件需要一定时间，取决于APK大小和USB传输速度
   - 建议在稳定的USB连接下运行

4. **存储空间**
   - 确保有足够的磁盘空间存储临时APK文件
   - 临时文件会在提取完成后自动清理

## 故障排除

### 问题1: 未检测到adb连接

**解决方案：**
1. 检查USB连接
2. 确认已开启USB调试
3. 在手机上授权此电脑的调试权限
4. 运行 `adb devices` 确认设备已连接

### 问题2: 无法获取APK路径

**可能原因：**
- 应用未安装
- 应用已被卸载
- 权限不足

**解决方案：**
- 确认应用已正确安装
- 检查adb权限

### 问题3: 拉取APK失败

**可能原因：**
- USB连接不稳定
- APK文件过大
- 存储空间不足

**解决方案：**
- 检查USB连接
- 确保有足够的磁盘空间
- 重试操作

### 问题4: 未找到图标文件

**可能原因：**
- 应用使用了非标准的图标命名
- 图标资源被混淆或加密

**解决方案：**
- 手动检查APK内容
- 使用其他工具（如APKTool）提取资源

## 后续步骤

提取图标后，你可以：
1. 查看提取的图标文件
2. 根据需要编辑或优化图标
3. 参考ART+图标规范制作适配图标
4. 将制作好的图标放入对应的应用目录
