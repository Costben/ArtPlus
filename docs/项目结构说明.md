## ADB工具管理

### 统一使用项目内的ADB

所有Python脚本已配置为自动使用 `platform_tools/` 目录中的adb工具：

- **无需配置系统PATH** - 脚本会自动查找项目内的adb
- **自动回退机制** - 如果项目内adb不存在，会自动使用系统PATH中的adb
- **跨平台支持** - 自动识别Windows/Linux/Mac系统

### 修改的脚本

以下脚本已更新为使用项目内的adb：

1. `extract_app_icons.py` - 应用图标提取工具
2. `check_artplus_icons.py` - 基础图标检测工具
3. `check_artplus_icons_enhanced.py` - 增强版图标检测工具

### 使用方式

#### 通过启动脚本（推荐）

按系统运行 `launch/` 目录下的脚本：
- Windows：`launch\windows\*.bat`
- macOS：`bash launch/macos/*.sh`
- Linux：`bash launch/linux/*.sh`

#### 通过命令行

```bash
# 从项目根目录运行
python cli/check_artplus_icons_enhanced.py
python cli/extract_app_icons.py
python cli/convert_and_organize_icons.py
```

#### 在代码中使用

```python
# 自动使用项目内的adb
import sys
from pathlib import Path

# 将src加入PYTHONPATH
project_root = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(project_root / "src"))

from adb_helper import get_adb_path
from project_helper import get_path

adb_path = get_adb_path()  # 获取项目内的adb路径
project_root = get_path(".")  # 获取项目根目录
```

## 优势

1. **项目自包含** - 不依赖系统环境配置
2. **版本统一** - 所有工具使用相同版本的adb
3. **易于部署** - 克隆项目即可使用，无需额外配置
4. **代码简洁** - 统一的adb路径管理

## 更新ADB工具

如果需要更新adb工具版本：

1. 从 [Android SDK Platform Tools](https://developer.android.com/tools/releases/platform-tools) 下载最新版本
2. 替换 `platform_tools/` 目录中的相应文件
3. 无需修改任何代码
