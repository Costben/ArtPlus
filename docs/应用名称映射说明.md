# 应用名称映射说明

## 功能说明

为了支持中文应用名称的匹配，系统会在提取APK时自动获取应用的中文显示名称，并保存到 `outputs/mappings/app_display_names.json` 文件中。

## 工作流程

### 步骤1: 提取APK并获取显示名称

运行 `python cli/extract_missing_apks.py`（或使用 `launch/` 下的 `02-拉取APK并提取和整理图标` 的第1步）时，脚本会：
1. 检查哪些应用缺少PNG图标
2. 通过adb获取每个应用的中文显示名称
3. 提取APK到手机 `Download/Apks` 目录
4. 将应用名称映射保存到 `outputs/mappings/app_display_names.json`

### 步骤2: 在手机上提取图标

使用手机上的图标提取工具提取图标，zip文件命名格式：
- `应用显示名称_icon.zip`
- 例如：`冰箱_icon.zip`、`果仁相册_icon.zip`、`gkd_icon.zip`

### 步骤3: 批量提取zip

运行 `python cli/extract_icon_zips.py` 时，脚本会：
1. 从 `outputs/mappings/app_display_names.json` 加载应用名称映射
2. 根据zip文件名中的应用名称匹配包名
3. 解压zip文件到 `outputs/new_artplus/包名/` 目录

## 文件格式

### outputs/mappings/app_display_names.json

```json
{
  "com.example.app1": {
    "package": "com.example.app1",
    "name": "com.example.app1",
    "display_name": "应用显示名称"
  },
  "com.example.app2": {
    "package": "com.example.app2",
    "name": "com.example.app2",
    "display_name": "另一个应用"
  }
}
```

## 匹配逻辑

脚本使用以下优先级匹配应用名称：

1. **精确匹配** - 直接匹配应用名称（保留大小写和空格）
2. **小写匹配** - 匹配小写版本
3. **去除空格匹配** - 去除空格、下划线、连字符后匹配
4. **模糊匹配** - 检查是否包含
5. **包名匹配** - 如果应用名称是包名的一部分

### 中文名称匹配示例

- `冰箱_icon.zip` → 匹配 `display_name: "冰箱"`
- `果仁相册_icon.zip` → 匹配 `display_name: "果仁相册"`
- `甲壳虫ADB助手_icon.zip` → 匹配 `display_name: "甲壳虫 ADB 助手"`（去除空格后匹配）
- `gkd_icon.zip` → 匹配 `display_name: "gkd"` 或包名中包含 "gkd"

## 注意事项

1. **首次运行** - 如果还没有 `outputs/mappings/app_display_names.json`，需要先运行 `python cli/extract_missing_apks.py` 来生成映射文件
2. **更新映射** - 每次运行 `python cli/extract_missing_apks.py` 都会更新映射文件，添加新的应用显示名称
3. **中文支持** - 确保zip文件名使用应用的实际显示名称（中文），而不是包名
4. **匹配失败** - 如果无法匹配，检查zip文件名是否与 `outputs/mappings/app_display_names.json` 中的 `display_name` 一致

## 手动添加映射

如果某些应用无法自动匹配，可以手动编辑 `outputs/mappings/app_display_names.json`：

```json
{
  "com.example.app": {
    "package": "com.example.app",
    "name": "com.example.app",
    "display_name": "应用的实际显示名称"
  }
}
```

保存后，重新运行 `python cli/extract_icon_zips.py` 即可。
