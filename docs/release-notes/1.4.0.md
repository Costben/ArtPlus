## What's New

### ✨ New Features
- Added preset feature tags and single-preset export for clipboard/share.
- Added Miuix bottom-sheet dialog with spring slide-up and dynamic window dim.
- Added preset library search, expanded list, action menu and delete confirm flow.
- Added root-target write confirm with remember-option and refresh auto-confirm toggle.

### 🐛 Fixes
- Fixed dropdown lists being anchored to the whole card and obscured by the floating bottom bar.

### 🔧 Improvements
- Downgraded JVM toolchain to 17 and added JSON test dependency for broader build compatibility.
