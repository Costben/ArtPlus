## What's New

### ✨ Features
- Reworked local rule generation parameters with one-tap style presets, grouped toggle sliders, and a collapsible low-level options section.
- Adaptive icons now support manual layer role assignment (subject / background / ignore) and preserve native foreground, night, and monochrome layers.
- Home page now supports horizontal swipe switching between tabs with synchronized top bar transitions.
- Presets list rebuilt as notification-style swipe cards; top 1×4 preview strip lifted into an independent frosted-glass overlay.
- Generated preview reworked into four full-bleed standalone wallpaper cards with frosted-glass bottom labels.

### 🎨 UI Polish
- Upgraded main app and Enhancer module UI to the latest COUI17 components, unifying card corners and list interactions across all pages.
- Fixed bottom bar flicker when opening/dismissing floating action menus and fixed top bar progressive blur when the 1×4 preview strip is enabled.
- General UI polish across preview, batch preview, presets, and app picker.

### 🔧 Logic Refinements
- Fixed adaptive icon clipping, layer drift, soft shadow truncation, and monochrome styling issues when writing icons.
- Adjusted default foreground subject scale to 70% and refined preview source selection behavior.

## 更新内容

### ✨ 新功能
- 重构稳定规则生成参数：新增四档一键快捷风格、常用带开关滑块及默认折叠的底层算法细项。
- 自适应图标支持手动分配图层角色（主体 / 背景 / 忽略），并完整保留原生前景、夜间与单色图层。
- 主页面支持左右滑动切换分页并联动顶栏平移。
- 预设列表改用通知式滑动卡片；顶部 1×4 预览条独立为毛玻璃浮层。
- 生成预览重构为四张独立满铺壁纸卡片，底边配实时毛玻璃标签栏。

### 🎨 UI 优化
- 主应用与增强伴侣模块全面迁移至新版 COUI17 组件，统一全应用卡片圆角与列表交互。
- 修复融合球菜单展开收起时底栏闪烁，以及开启顶部 1×4 预览条后顶栏呈实心面板的问题。
- 生成预览、批量生成预览、预设页与选择应用页整体 UI 优化。

### 🔧 逻辑优化
- 修复自适应图标写入后变成直角方板、不跟随单色风格、图层偏移及前景柔和阴影被截断的问题。
- 调整前景主体默认占比为 70%，优化预览来源面板选择逻辑。
