## What's New

- Fix card top/bottom padding missing for tuning cards where the slider was sticking to the rounded edge. Restored 12dp vertical padding and ensured press highlight covers the padding on first/last rows.

- Expanded summaries now show full text via horizontal marquee only while the slider is expanded, matching the Settings page behavior.
