## What's New

### ✨ Features
- Refreshed interface with ColorOS 17 (COUI17) design language, including reworked top bars, bottom navigation, and scroll coordination.
- Introduced companion LSPosed Enhancer module for desktop liquid glass (dock frosted glass tray + icon rim light) and morph asset takeover.
- Full adaptive icon and Android 13+ themed icon support, eliminating launcher-enforced white backgrounds.
- Presets list reworked into stacked standalone cards; app picker actions unified into a fused floating pill.

### 🎨 UI Polish
- Dialogs upgraded to translucent frosted glass style; smoother cross-fade page transitions.
- General UI polish across home, presets, picker, and about pages.

### 🔧 Logic Refinements
- Reworked state and rendering pipeline for faster startup and smoother tab switching.
- Memory management optimizations and icon cache lifecycle improvements.

## 更新内容

### ✨ 新功能
- 界面全面重做为 ColorOS 17（COUI17）设计风格，重构顶栏、底栏与联动滚动。
- 新增独立的 LSPosed 增强伴侣模块，支持桌面液态玻璃（Dock 毛玻璃托盘 + 图标边缘光）与可变图标接管。
- 全面支持自适应图标（Adaptive Icon）与 Android 13+ 主题单色图标，消除桌面强制白底。
- 预设列表重构为独立平铺卡片布局；选择应用底部操作适配融合操作球。

### 🎨 UI 优化
- 弹窗对话框升级为半透明磨砂质感；页面切换支持淡入淡出动画过渡。
- 主页、预设页、应用选择页与关于页整体 UI 优化。

### 🔧 逻辑优化
- 重构状态与渲染管线，提升冷启动与切页流畅度。
- 优化内存管理与图标缓存释放机制。
