## What's New

### 🎨 UI / UX
- Four main tabs (Home / Generation Params / Presets / Settings) now render independently, so switching between them is smoother and the app resumes where you left off after a font-size or split-screen change.
- Icon glyphs across settings and toolbar entries were unified to one visual family.
- Spacing, corner radius and the bottom-bar clearance now follow a single set of size tokens, so the page no longer shifts when the floating bar changes state.
- Accessibility labels were added to functional icons; decorative artwork is marked as such for screen readers.

### 🔧 Logic Refinements
- Writing generated icons, saving settings and rebuilding previews now share one code path, removing the cases where a save could silently skip a field.
- Preview assets rebuild only when a visual parameter actually changes; editing unrelated fields (for example an AI prompt) no longer re-decodes the preview images.
- Fixed the system-app toggle in the app picker occasionally reverting to its previous state.
- Fixed stale status text and busy indicators on the generation card.
- Preset list loading no longer blocks the first frame.

## 更新内容

### 🎨 界面
- 主页 / 生成参数 / 预设 / 设置 四个页面改为各自独立渲染，切换更顺；字体缩放、分屏后返回不再丢状态。
- 设置项与顶栏图标统一为同一套图标风格。
- 间距、圆角与底栏让位改为统一尺寸 token，底栏状态变化时页面不再跳动。
- 功能性图标补齐无障碍描述，纯装饰图标注为装饰。

### 🔧 逻辑优化
- 图标写入、设置保存、预览重建收敛到同一条代码路径，修掉「保存时漏字段」的可能。
- 预览只在视觉参数变化时重建；改 AI 提示词等无关字段不再重新解码预览图。
- 修复应用选择页「显示系统应用」开关偶发回弹。
- 修复生成卡片的忙碌状态与状态文案不刷新。
- 预设列表读取不再阻塞首帧。
