## What's New

### ✨ Features
- Presets list rebuilt as native notification-style swipe cards: swipe left to reveal more and delete, active preset highlighted with an outline.
- Top preview strip lifted into its own frosted-glass overlay, staying sharp above the scrolling list and blurring content behind it.

### 🎨 UI Polish
- Batch preview renamed to "Batch Preview"; style labels shortened so they no longer truncate.
- Exporting presets now confirms with a toast.

### 🔧 Logic Refinements
- "Only AM Apps" filter now keeps ungenerated apps visible and narrows only the generated ones.
