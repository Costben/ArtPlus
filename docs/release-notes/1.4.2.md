## What's New

### ✨ Features
- Reworked batch preview page: scrollable layout, framed desktop preview with 4 style tabs, and tuning controls matching the home page.
- "Desktop" background now uses the real system wallpaper (ColorOS default bundled as fallback); custom wallpapers can be uploaded in Settings.
- Smoother secondary-page transitions with dimming and large rounded corners.

### 🎨 UI Polish
- General UI polish across the preview page.

### 🔧 Logic Refinements
- Logic refinements to preview sampling, caching, and wallpaper loading.
