## What's New

### ✨ Features
- Batch preview controls now reuse the home page parameter rows (columns / icon size / corner radius) with manual input, collapsed by default and without leading icons.
- The "Desktop" background reads the device's actual system wallpaper with its aspect ratio preserved; the bundled fallback is now a ColorOS default wallpaper.
- New wallpaper card in Settings: upload any custom wallpaper (auto center-cropped to 16:9, never scaled or distorted) or clear it to fall back to system/bundled wallpaper.

### 🔧 Improvements
- Removed the bottom apply bar on the batch preview page; it is preview-only now, apply presets from the preset list instead.
- The top bar collapses on scroll like the home page, and the preview frame height is locked to content rows + 1 so scrolling inside the frame no longer steals gestures.
- Back and refresh buttons in the top bar are now perfectly mirrored at equal distance from the screen centerline.

## 更新内容

### ✨ 新功能
- 批量预览控制区改用主页同款参数行（列数 / 图标大小 / 图标圆角），支持手动输入，默认收起且无行首图标。
- 「桌面」背景直读当前设备系统壁纸（保留原始比例）；内置兜底图换成 ColorOS 默认壁纸。
- 设置页新增壁纸卡片：可上传任意自定义壁纸（自动居中裁剪 16:9，不缩放不变形），也可一键清除恢复系统壁纸/内置壁纸。

### 🔧 优化
- 批量预览页移除底部套用栏，只做纯预览；套用请回预设列表操作。
- 顶栏支持下滑折叠（与主页一致）；预览框高度锁死为内容行数 + 1，框内不再抢夺滚动手势。
- 顶栏返回与刷新按钮严格镜像，到屏幕中线距离完全相等。
