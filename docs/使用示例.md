# 使用示例

## 示例1: 通过adb获取应用列表

1. 确保手机已连接并开启USB调试
2. 运行工具：
   ```bash
  python cli/check_artplus_icons_enhanced.py
   ```
3. 选择选项 `1`
4. 等待工具完成检测
5. 查看生成的报告文件

## 示例2: 从文件读取应用列表

### 步骤1: 导出应用列表

使用adb命令导出应用列表：
```bash
adb shell pm list packages -3 > apps.txt
```

### 步骤2: 运行工具

```bash
python cli/check_artplus_icons_enhanced.py
```

选择选项 `2`，输入文件路径 `apps.txt`

### 步骤3: 查看结果

工具会生成三个文件（默认输出到 `outputs/reports/`）：
- `missing_artplus_icons.txt` - 文本报告
- `missing_artplus_icons.json` - JSON数据
- `missing_artplus_icons.html` - HTML可视化报告

## 示例3: 仅查看已适配的应用

```bash
python cli/check_artplus_icons_enhanced.py
```

选择选项 `3`，会列出所有已适配ART+图标的应用包名。

## 自定义目录路径

如果ART+图标目录不在默认位置，可以修改脚本中的路径：

```python
checker = ArtPlusIconChecker(
    artplus_path1="你的路径/theme/uxicons/hdpi",
    artplus_path2="你的路径/uxicons"
)
```
