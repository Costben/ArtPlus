# 项目整理说明

## 整理内容

项目已重新组织，使结构更加清晰：

### 目录结构

```
ArtPlus/
├── cli/                  # ✅ CLI入口脚本
│   └── ...所有CLI脚本
├── src/                  # ✅ 共享模块
│   ├── adb_helper.py
│   ├── project_helper.py
│   └── ...其他模块
├── docs/                 # ✅ 文档目录
│   ├── README.md
│   └── ...所有.md文件
├── launch/               # ✅ 启动脚本（按系统分类）
│   ├── windows/          # *.bat
│   ├── macos/            # *.sh
│   └── linux/            # *.sh
├── outputs/              # ✅ 标准输出目录
│   ├── new_artplus/       # 新生成的ART+图标
│   ├── reports/          # 报告与统计
│   ├── mappings/         # 名称映射
│   ├── tmp/              # 临时文件
│   └── archives/         # 压缩包/归档
├── tests/                # ✅ 测试资源与样例
├── platform_tools/       # Android平台工具
├── theme/                # 主题文件
├── uxicons/              # ART+图标目录
├── README.md             # 项目主文档
└── requirements.txt      # Python依赖
```

### 主要变更

1. **CLI与模块分层** → CLI放到 `cli/`，共享模块放到 `src/`
2. **所有Markdown文档** → 移动到 `docs/` 目录（README.md保留在根目录）
3. **输出统一** → 所有Python输出集中到 `outputs/` 目录
4. **启动脚本** → 按系统分类放入 `launch/` 目录
5. **路径更新** → 所有脚本与文档已更新路径引用

### 更新的文件

#### 启动脚本
- `launch/windows/*.bat` - Windows 启动脚本
- `launch/macos/*.sh` - macOS 启动脚本
- `launch/linux/*.sh` - Linux 启动脚本

#### Python脚本
- CLI脚本位于 `cli/`，共享模块位于 `src/`
- 所有脚本添加了路径处理，支持从项目根目录运行
- `project_helper.py` 用于统一管理项目路径
- `adb_helper.py` 支持跨平台adb/aapt路径

### 使用方式

#### 方式1: 使用启动脚本（推荐）

按系统运行 `launch/` 目录下的脚本即可，无需修改路径。

#### 方式2: 命令行运行

从项目根目录运行：

```bash
python cli/check_artplus_icons_enhanced.py
python cli/extract_app_icons.py
python cli/convert_and_organize_icons.py
```

### 优势

1. **结构清晰** - 脚本、文档、工具分类明确
2. **易于维护** - 相关文件集中管理
3. **根目录简洁** - 只保留必要的启动文件
4. **向后兼容** - 批处理文件使用方式不变
