# 图标前景背景分离说明

## 功能说明

`cli/separate_icon_layers.py` 用于将图标PNG文件分离为前景和背景两张图片。

## 安装依赖

### 基础依赖（必需）
```bash
pip install Pillow
```

### 方法1: 透明通道分离（无需额外依赖）
- 如果PNG已经有透明通道，直接使用，性能最好
- 无需安装任何额外库

### 方法2: OpenCV GrabCut（推荐，轻量级）
```bash
pip install opencv-python
```
- **优点**: 轻量级，不需要下载模型，性能占用小
- **缺点**: 对于复杂背景可能效果一般
- **适用**: 图标背景相对简单的情况

### 方法3: rembg（效果最好，但需要下载模型）
```bash
pip install rembg
```
- **优点**: 效果最好，基于深度学习
- **缺点**: 首次使用需要下载模型（约170MB），内存占用较大
- **适用**: 需要高质量分离的场景

## 使用方法

### 1. 处理单个文件

```bash
# 自动选择最佳方法
python cli/separate_icon_layers.py path/to/icon.png

# 指定输出目录
python cli/separate_icon_layers.py path/to/icon.png -o output_dir

# 指定方法
python cli/separate_icon_layers.py path/to/icon.png -m grabcut
```

### 2. 批量处理目录

```bash
# 处理目录中所有PNG文件
python cli/separate_icon_layers.py path/to/directory

# 指定方法
python cli/separate_icon_layers.py path/to/directory -m auto
```

### 3. 方法选择

- `auto` (默认): 自动选择最佳方法
  1. 先尝试透明通道方法（最快）
  2. 如果失败，尝试GrabCut（轻量级）
  3. 如果失败，尝试rembg（效果最好）

- `alpha`: 仅使用透明通道方法
- `grabcut`: 仅使用OpenCV GrabCut算法
- `rembg`: 仅使用rembg库

## 输出文件

对于输入文件 `icon.png`，会生成：
- `icon_foreground.png`: 前景图片（背景透明）
- `icon_background.png`: 背景图片（白色背景，前景区域透明）

## 性能对比

| 方法 | 速度 | 内存占用 | 模型大小 | 效果 |
|------|------|----------|----------|------|
| 透明通道 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 无 | ⭐⭐⭐⭐ |
| GrabCut | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 无 | ⭐⭐⭐ |
| rembg | ⭐⭐⭐ | ⭐⭐⭐ | ~170MB | ⭐⭐⭐⭐⭐ |

## 推荐方案

1. **如果图标已有透明通道**: 使用方法1（透明通道），最快最简单
2. **如果图标没有透明通道，且背景简单**: 使用方法2（GrabCut），轻量级
3. **如果需要高质量分离**: 使用方法3（rembg），效果最好

## 示例

```python
import sys
from pathlib import Path

# 将cli加入PYTHONPATH
project_root = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(project_root / "cli"))

from separate_icon_layers import separate_icon_layers

# 分离单个图标
separate_icon_layers(
    Path("icon.png"),
    output_dir=Path("output"),
    method="auto"
)
```
