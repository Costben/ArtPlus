# outputs/new_artplus 目录结构整理说明

## 整理目标

使 `outputs/new_artplus` 内的包名文件夹内部结构与官方ART+图标目录结构完全一致。

## 官方结构

官方ART+图标目录结构（以 `uxicons/air.tv.douyu.android/` 为例）：

```
包名文件夹/
├── recbg.png              # 经典亮色背景（240x240）
├── recbg_1x2.png          # 经典亮色背景（240x820）
├── recbg_2x1.png          # 经典亮色背景（820x240）
├── recbg_2x2.png          # 经典亮色背景（704x704）
├── recfg.png              # 经典亮色前景（240x240）
├── recfg_1x2.png          # 经典亮色前景（240x820）
├── recfg_2x1.png          # 经典亮色前景（820x240）
├── recfg_2x2.png          # 经典亮色前景（704x704）
├── rec_night.png          # 经典暗色（240x240）
├── rec_night_1x2.png      # 经典暗色（240x820）
├── rec_night_2x1.png      # 经典暗色（820x240）
├── rec_night_2x2.png      # 经典暗色（704x704）
├── monochrome.png         # 灵感样式（240x240）
├── monochrome_1x2.png     # 灵感样式（240x820）
├── monochrome_2x1.png     # 灵感样式（820x240）
├── monochrome_2x2.png     # 灵感样式（704x704）
├── day.png                # 彩昼样式（240x240）
├── nsd.png                # 夜影样式（240x240）
├── mat.png                # 材料样式（240x240）
└── peb.png                # 鹅卵石样式（240x240）
```

**特点：**
- 所有ART+图标文件直接放在包名文件夹根目录
- 没有子目录
- 没有README.txt等说明文件
- 没有preview.png等预览文件

## 整理后的结构

整理后的 `outputs/new_artplus/包名/` 结构：

```
包名文件夹/
├── [所有ART+图标文件]     # 与官方结构完全一致
└── src/                   # 可选：存放原始提取的文件
    ├── mipmap-xxxhdpi-v4_ic_launcher.png
    ├── mipmap-xxhdpi-v4_ic_launcher.png
    └── ...其他原始文件
```

## 整理内容

### 1. 文件移动
- 将 `src/` 目录中的ART+图标文件移动到包名文件夹根目录
- 确保所有官方ART+图标文件都在根目录

### 2. 文件删除
- 删除 `README.txt`（非官方文件）
- 删除 `preview.png`（预览文件，非官方格式）
- 清理 `src/` 目录中的非必要文件

### 3. 目录保留
- `src/` 目录保留，用于存放原始提取的文件（如mipmap文件、XML文件等）
- 如果 `src/` 目录为空，会自动删除

## 注意事项

1. **备份重要文件** - 整理前建议备份 `outputs/new_artplus` 目录
2. **src目录** - 原始提取的文件会保留在 `src/` 目录中，不会丢失
3. **重复运行** - 可以安全地重复运行整理脚本，不会造成数据丢失
4. **部分应用** - 如果某个应用还没有生成完整的ART+图标，只会整理已存在的文件
